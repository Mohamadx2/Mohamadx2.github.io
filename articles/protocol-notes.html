PROTOCOL_NOTES

STATUS :: PUBLISHED · CHANNEL :: OPEN · TYPE :: NOTES

These are working notes, not finished doctrine. They exist because constraint keeps forcing better decisions than freedom does.

// 01 — LIMIT THE PALETTE

One accent colour. One typeface. One background treatment. Everything else is noise that competes with the message. When the interface can only speak in green-on-black, the hierarchy has to be earned through spacing, weight and silence.

Rule of thumb: if a new element does not increase clarity, it decreases it.

// 02 — STATIC IS A FEATURE

A page that does not need a build step, a package manager or a runtime can be understood in one sitting. That understanding is the point. Complexity that is not required is technical debt paid in attention.

// 03 — SHIP THE SIGNAL

The goal is not a perfect site. The goal is a clear channel. Publish the entry, link the project, leave the contact open. Then move to the next transmission.
